# TTS bake-off

A listening comparison of open-source French TTS engines for the dictation, run server-side on CPU:
Piper, Kokoro-82M, Chatterbox Multilingual, Coqui XTTS-v2 and F5-TTS (French fine-tune). Nothing here
is used by the game. Docker only: each engine has its own image (`<engine>/Dockerfile`), weights stay
in the `discorde-tts-cache` volume.

    tools/tts/run_docker.sh bake piper      # then kokoro, chatterbox, xtts, f5: one at a time
    tools/tts/run_docker.sh post            # atempo stretches, pauses, image sizes, index.html

`lines.json` holds the spoken strings, made by the game's own code (`buildPlan`, `splitChunks`,
`spokenForm`, dialogue `fill` + `frenchSpacing`). Samples, timings and the listening page
(`index.html`) land in `assets/tts-bakeoff/`, which is not committed. `licences.json` records each
engine's and voice's licence as its source states it. Only built-in or bundled voices are used.

`lines.json` is regenerated by `lines.ts` (bundled with the repo's esbuild, run with node, both in the
node container):

    scripts/npm.sh exec -- esbuild ../tools/tts/lines.ts --bundle --platform=node --format=esm \
      '--alias:$lib=./src/lib' --alias:@content=../content --outfile=.cache/tts-lines.mjs
    scripts/npm.sh exec -- node .cache/tts-lines.mjs ../tools/tts/lines.json
