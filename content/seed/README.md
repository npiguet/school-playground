# Seed passages — sources and public-domain rule

Public-domain rule (spec §3.2): every non-original passage is kept only if
**both the original author and the translator (when there is one) died
before 1956** (Swiss law: life + 70 years, checked against 2026). Death
years below were verified against French Wikipedia and Wikisource author
pages during this import; see each file's `author_death` /
`translator_death` / `license_note` fields for the exact values shipped
with the text. Original myth passages (`"original": true`) are credited to
`"Les Muses de la Discorde"` and carry no `source_url`; they are not
public-domain reuses, they are written for this game.

Homère (trad. Victor Bérard) — the plan's target list called for three
Odyssey passages (Polyphème's cave, Nausicaa, Circé's island). Bérard's
translation (died 1931) is not available on fr.wikisource.org as a clean,
fully transcribed text (only facsimile page scans, no validated "Texte
entier"), and Gutenberg only carries the Leconte de Lisle translation,
whose Hellenised proper names ("Akhilleus" and the like) are unsuitable
for this game. Per the plan's instructions, these three passages were
dropped and replaced with three original myth passages on the same
subjects (`033-muses-polypheme`, `034-muses-nausicaa`, `035-muses-circe`),
written by Les Muses de la Discorde instead of translated.

## Cutting notes

Every passage is verbatim from its source (original spelling and
punctuation kept, only cut at sentence boundaries; a few connecting
sentences were dropped to fit the 80–200 word window, never rewritten).
None contains digits — numbers, where the source used any, were avoided
by choosing a different cut. `server/app/tools/seed_check.py` (added in a
later task) annotates these files with spaCy and checks the minimum
verb/nominal-group counts referenced in the plan.
